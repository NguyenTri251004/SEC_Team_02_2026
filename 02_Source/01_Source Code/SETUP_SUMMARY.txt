## 🔐 Authentication Options

### Option A: Quick Testing (Recommended)
```bash
cd backend
node generate-token.js  # Generates token valid for 1 hour
# Copy token and use it
```

### Option B: Real Keycloak Token
1. Create user in Keycloak admin console: http://localhost:8080/admin (admin/admin)
2. Get token via OAuth2:
```bash
curl -X POST http://localhost:8080/realms/inventory-management/protocol/openid-connect/token \
  -d "grant_type=password" \
  -d "client_id=admin-cli" \
  -d "username=youruser" \
  -d "password=yourpass"
```

### Option C: Development Mode (No Token)
Set `BYPASS_AUTH=true` in docker-compose.yml and restart backend:
```bash
docker compose restart ims-backend
```

## 🆘 Having Issues?

### Prometheus/Grafana not loading?
1. Verify containers running: `docker compose ps`
2. Check logs: `docker compose logs ims-prometheus`
3. Wait 60 seconds for health checks
4. Refresh browser (Ctrl+F5)

### Token not working?
1. Generate fresh token: `cd backend && node generate-token.js`
2. Verify token copied correctly (no spaces)
3. Check token expiration: Tokens valid for 1 hour

### Metrics not showing?
1. Make some API requests: `Invoke-WebRequest http://localhost:3000/health`
2. Wait 30 seconds for Prometheus scrape interval
3. Refresh Grafana dashboard
4. Check Prometheus targets at: http://localhost:9090/targets
